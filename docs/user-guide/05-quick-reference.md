# Quick reference

## Which button, which role

| I want to…                       | Where                                                                   | Role needed                                            |
| -------------------------------- | ----------------------------------------------------------------------- | ------------------------------------------------------ |
| Submit a brief                   | Home → **New brief**                                                    | Account Manager / Sales Coordinator                    |
| See my briefs / search           | **Briefs**                                                              | anyone signed in (you see what your role allows)       |
| Approve or reject a sign-off     | **Approvals**                                                           | Approver + the approval role                           |
| Veto a sign-off                  | **Approvals → Veto**                                                    | General Manager (veto)                                 |
| Reverse a veto                   | Brief page → **Reverse veto**                                           | Admin                                                  |
| Add a person or change roles     | **People and roles**                                                    | Admin                                                  |
| Change scoring rules             | **Rule sets**                                                           | Admin                                                  |
| Look up a code                   | **Verify a code**                                                       | Auditor or Admin                                       |
| See trends                       | **Dashboard**                                                           | Auditor, Admin, General Manager or Commercial Director |
| See one Account Manager's briefs | **Briefs → Account Manager** filter, or **Dashboard → Account Manager** | Admin, Auditor, General Manager or Commercial Director |

## The outcome, in order

1. **Score and commercial decision** (instant): Auto-approved / Pending / Declined.
   - Declined: score at or below **30**. Auto-approved: above **115**. In between: Pending.
   - Always Auto-approved: _Rework (Of Selling)_ and _Niche/Fine Fragrance pre-approved_.
2. **Sign-offs** (people), raised independently of the commercial decision:

| Sign-off                  | Raised when                       | Role                                                         |
| ------------------------- | --------------------------------- | ------------------------------------------------------------ |
| Short deadline            | Deadline 14 days or fewer away    | Development Director                                         |
| Creative (creation)       | Creation/Unknown, tier not A or T | Development Director                                         |
| Creative (starting point) | Starting Point, tier C or D       | Development Director                                         |
| Marketing / PPD / GCMS    | The box is ticked                 | Divisional Head Marketing / PPD Manager / Analytical Manager |
| Tier T                    | Tier T (when enabled)             | Commercial Director                                          |

3. **Approval Code** when all sign-offs are Approved or Pre-approved and the brief isn't declined.

## Rules of the road

- A brief can be _commercially Auto-approved_ and still **Pending**: no code until every sign-off clears.
- Rejecting needs a comment. A veto needs a reason. Reversing a veto needs a reason.
- Pre-approval: the named manager has **72 hours** to revoke, once, from the email link.
- You can't approve a brief you submitted; those sign-offs go to an Admin.
- Role changes apply the **next time you sign in**.
- Nothing is ever deleted. Everything is in the audit trail.

## Emails the app sends

| Email                                   | Sent to                                                                                   |
| --------------------------------------- | ----------------------------------------------------------------------------------------- |
| Sign-off needed                         | Everyone who holds the approval role (Admins if the submitter would be the only approver) |
| Brief approved (with the Approval Code) | The submitter, and the Account Manager of record if different                             |
| Sign-off rejected (with the comment)    | The submitter, and the Account Manager of record if different                             |
| Pre-approval declared                   | The manager named                                                                         |
| Pre-approval revoked                    | The submitter                                                                             |
| Brief vetoed / Veto reversed            | The submitter                                                                             |

Not sent: reminders about sign-offs that are still waiting; a confirmation to the person who just submitted a brief.
Emails can take up to about five minutes.
